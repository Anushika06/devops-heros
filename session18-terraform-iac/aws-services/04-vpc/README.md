# 04. VPC - Networking
- **What is VPC?**: Virtual Private Cloud; isolated virtual network in AWS.
- **CIDR**: Classless Inter-Domain Routing; method for allocating IP addresses and IP routing.
- **Subnets**: Subdivisions of a VPC network (can be public or private).
- **Route Tables**: Rules directing network traffic from subnets.
- **Internet Gateway**: Allows communication between VPC and the internet.
- **NAT Gateway**: Allows instances in private subnets to connect to the internet (outbound only).
- **Security Groups**: Instance-level firewalls.
- **Network ACLs**: Subnet-level firewalls (stateless).
- **Public vs Private Subnet**: Public has a route to the IGW; Private does not.
- **Common Use Cases**: Securely hosting multi-tier web applications.
