# 01. IAM - Governance
- **What is IAM?**: Identity and Access Management; securely manages access to AWS services and resources.
- **Users**: Individuals or applications needing access.
- **Groups**: Collections of users with identical permissions.
- **Roles**: Assumable identities with specific permissions (often for services/applications).
- **Policies**: JSON documents defining allowed/denied actions.
- **Permissions**: Rules dictating what can be done.
- **Least Privilege**: Best practice of granting only the permissions required for a task.
- **Best Practices**: Use roles, enable MFA, rotate credentials, apply least privilege.
- **Common Use Cases**: Granting EC2 access to S3, managing human user access.
